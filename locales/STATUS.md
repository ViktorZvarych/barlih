# Стан мовних файлів

- `uk`: заповнено ключі поточного каркаса на основі ТЗ.
- `en`, `pl`: ті самі змістові ключі, чернетки з `reviewStatus: NEEDS-REVIEW`; перевірка носіями — на Кроці 6.
- Форми множини: uk/pl — `one`, `few`, `many`, `other`; en — `one`, `other` (виняток відповідно до B18.3).
- Нові ключі додаються синхронно під час відповідних кроків. Повні тексти майбутніх секцій на Кроці 0 не створюються.
- `npm run build:prod` відхиляє невирішені позначки; готовність каркаса не означає готовність до публікації.
