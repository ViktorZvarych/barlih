# Збірка та публікація Barlih

## Стан Кроку 0

Це каркас для локальної розробки. Публікація — після Кроку 7 і критеріїв B17. Сторінки зараз мають `noindex, nofollow`; en/pl потребують перевірки носіями, фото — заміни. На цьому кроці нічого на хостинг не завантажується.

## Локально

Node.js ≥ 18 потрібен тільки розробнику. Збірка не потребує зовнішніх залежностей. Fontsource встановлено лише як dev-інструмент; до dist копіюються готові WOFF2 та OFL, без npm-пакетів.

```sh
npm run build
npm test
npm run package
python -m http.server 8081 --bind 127.0.0.1 --directory dist
```

Перевірити `http://127.0.0.1:8081/`, `/en/`, `/pl/`. Пакет працює на простому статичному HTTP-сервері. Node.js і PHP на хостингу не потрібні.

## Пакет dist/

`npm run package` щоразу збирає мовні сторінки, перевіряє абсолютний шлях і заново формує лише локальний каталог `dist/` за білим списком B20.2. Вихідні файли зберігаються.

- Публічні HTML, ресурси `assets/`, `styles/`, `scripts/`, `data/availability.json`, sitemap; інші дозволені B20.2 файли — коли будуть створені на своїх кроках.
- Не копіюються `.ics`, `.env*`, `.git`, `node_modules`, Markdown, `templates/`, `locales/`, `tools/`, `tests/`, `package.json`; символічні посилання відхиляються.
- Демо-модулі виключаються, коли `CONFIG.flags.showDemoData = false`. Перед публікацією обов'язково вимкнути демо.
- Після копіювання пакет перевіряється на приватні файли. `--prod` також відхиляє `TODO-OWNER`, `NEEDS-REVIEW`, `LEGAL-REVIEW`; поточний каркас навмисно не проходить продакшн-збірку.
- На **Кроці 7** додаються мінімізація HTML/CSS/JS (видалення коментарів і зайвих пробілів/переносів), `.htaccess`, сторінка 404 та остаточні перевірки. Позначки перевіряються до видалення коментарів.

## Перед майбутньою публікацією

Завершити Кроки 1–7 та B17; прибрати всі позначки, перевірити юридичні тексти, фото, переклади, форму й актуальність календаря. Вимкнути демо, налаштувати підтверджений endpoint для реальних заявок, переглянути індексацію. Остаточні правила HTTPS, стиснення, кешування й безпеки — Крок 7.

```sh
npm run package -- --prod
```

Після успішної перевірки завантажити **вміст `dist/` у корінь домену** `barlih.info` через SFTP/FTPS або файловий менеджер хостингу. Шляхи ресурсів кореневі. Не завантажувати весь робочий проєкт. На сервері мають лишитися тільки статичні файли, без Node.js/PHP для роботи сайту.
